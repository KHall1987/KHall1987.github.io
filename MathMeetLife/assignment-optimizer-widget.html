How the widget decides

This is a one-to-one binary linear assignment problem. Every person receives exactly one item, and every item is used exactly once.

1

Build utilities

Each item attribute contributes +1, −1, or 0 according to that person’s preference state.

2

Search valid matchings

The solver considers only one-to-one assignments that use every person and item once.

3

Compare objectives

One solution prioritizes the total; the other compares minimum utility before total utility.
