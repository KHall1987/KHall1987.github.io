1. Crochet instructions

Grouped colour lines and the earlier inline <Yarn> format are both accepted.

Graph export options

Colours are stored on vertices. When yarn-coloured edges are enabled, each stitch colours its outgoing neighbour edge and each parent edge uses the child stitch colour.

2. Graph JSON

Paste this object directly into the Global Geodesic Graph Layout input.

RoundStitchesChangeParent edgesYarns
Accepted operation syntax

The parser understands SC, SC x 4, INC, INC x 3, DEC, SC2TOG, SC3TOG, 2 SC in next st, and split-colour increases written as SC in next st followed by SC again in same st.

Round 3: 12 -> 17 (increase 5)
   Blue: INC, SC x 2  {4}
   Green: INC          {2}
   Blue: SC, INC, SC, INC, SC x 2, INC, SC  {11}
   [17 stitches]
The converter produces the vertices[] and edges[] structure accepted by Global Geodesic Graph Layout, including optional seed coordinates and yarn-coloured edges.
